# Prompt: Sinh thêm từ vựng cho bảng `words`

Dùng prompt này khi cần tìm và thêm từ vựng mới vào DB của app học từ vựng (Spring Boot + Liquibase + SQL Server).

## Bối cảnh

- Bảng `words` hiện có **3744 từ** (BEGINNER: 1572, INTERMEDIATE: 1598, ADVANCED: 574), cột `word` có `UNIQUE` constraint.
- Schema insert (8 cột theo đúng thứ tự):
  `word, pronunciation, meaning_vi, part_of_speech, difficulty, category, example_sentence, example_translation`
- `difficulty` chỉ nhận: `BEGINNER`, `INTERMEDIATE`, `ADVANCED`.
- `part_of_speech`: `noun`, `verb`, `adjective`, `adverb`, `phrase` (cho idiom/phrasal verb/cụm từ).
- `category` nên dùng lại nhóm đã có (Business, Technology, Science, Health, Nature, Character, Emotions, Food, Travel, Language, Home, Time, Social, Entertainment, General, Descriptive, People, Animals, Body, Clothing, Places, Politics, Work, Transport, Education) — chỉ tạo category mới khi thực sự cần.

## Nhiệm vụ

1. **Không đề xuất lại từ đã có** — checklist đầy đủ ở cuối file này. Luôn kiểm tra (Ctrl+F / grep) trước khi thêm từ mới, dù câu SQL cũng có `WHERE NOT EXISTS` để tự chặn trùng ở runtime — kiểm tra trước giúp không tốn công soạn từ trùng.
2. **Thứ tự ưu tiên bắt buộc: BEGINNER trước → INTERMEDIATE → ADVANCED sau cùng.** Chỉ chuyển sang mức tiếp theo khi đã tìm đủ từ cơ bản còn thiếu ở mức hiện tại. Ưu tiên các từ thông dụng, tần suất dùng cao trong đời sống hàng ngày trước khi tới từ chuyên ngành/hiếm.
3. Mỗi từ cần đủ 8 trường: phiên âm IPA chuẩn, nghĩa tiếng Việt ngắn gọn, từ loại, độ khó, category, 1 câu ví dụ tiếng Anh tự nhiên + bản dịch tiếng Việt sát nghĩa.
4. Xuất kết quả thành 1 file Liquibase changeset mới (`0XX-seed-words-batchNN.sql`), theo đúng format các file cũ:

```sql
--liquibase formatted sql

--changeset vocab:0XX-seed-words-batchNN
INSERT INTO words (word, pronunciation, meaning_vi, part_of_speech, difficulty, category, example_sentence, example_translation)
SELECT v.word, v.pronunciation, v.meaning_vi, v.part_of_speech, v.difficulty, v.category, v.example_sentence, v.example_translation
FROM (VALUES
-- Category A
(N'word1', N'/ipa/', N'nghĩa', N'noun', N'BEGINNER', N'Category', N'Example sentence.', N'Câu ví dụ tiếng Việt.'),
...
) AS v(word, pronunciation, meaning_vi, part_of_speech, difficulty, category, example_sentence, example_translation)
WHERE NOT EXISTS (SELECT 1 FROM words w WHERE w.word = v.word);

--rollback DELETE FROM words WHERE word IN ('word1', ...);
```

5. Đăng ký file mới vào `db.changelog-master.xml` (thêm 1 dòng `<include file=".../0XX-seed-words-batchNN.sql"/>` cuối danh sách).
6. **Lưu ý quan trọng:** Liquibase auto-run đang bị tắt (`spring.liquibase.enabled: false` trong `application.yml`) — file changelog mới sẽ KHÔNG tự áp dụng vào DB khi service restart. Sau khi tạo file, chạy trực tiếp bằng `sqlcmd` để áp ngay vào DB thật:
   ```
   sqlcmd -S localhost -d vocab_db -U sa -P "<password>" -C -f 65001 -i "<đường dẫn file .sql>"
   ```
